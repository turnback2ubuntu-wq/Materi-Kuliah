## ✨ Fitur Slide Interaktif (Bolt Slides Engine)

Setiap dek presentasi dilengkapi dengan:
- **Reflow Responsif Penuh**: Layout cair adaptif yang tidak pernah terpotong di layar proyektor rasio 4:3, 16:9, laptop, maupun perangkat mobile.
- **Presenter Mode (`P`)**: Tampilan khusus pemateri dengan pewaktu (timer), slide preview berikutnya, dan catatan pembicara (speaker notes) yang tersinkronisasi via `BroadcastChannel`.
- **Anotasi & Coretan Layar (`A`)**: Fasilitas coret-coret pena digital langsung di atas elemen slide tanpa merusak DOM asli.
- **Click-Builds (`Space` / `→`)**: Animasi penyingkapan konsep bertahap (`<Build at={n}>`) untuk menjaga ritme penjelasan dosen.
- **Komponen Interaktif Kaya**: Visualisasi Matriks Comparison, Bento Grid, Before/After Contrast, BigNumber CountUp, dan CodeWindow dengan sintaks R berwarna.

## ⌨️ Pintasan Keyboard Saat Presentasi

| Tombol | Fungsi |
| :--- | :--- |
| `Space` / `→` | Maju ke langkah build berikutnya / pindah ke slide selanjutnya |
| `←` | Kembali ke slide sebelumnya |
| `P` | Membuka **Presenter Mode** di tab baru (tersinkronisasi) |
| `A` | Mengaktifkan **Anotasi / Coretan Layar** |
| `G` | Tampilan **Grid Overview** (semua slide dalam satu layar) |
| `S` | Tampilan **Thumbnail Sidebar** |
| `F` | Mode Layar Penuh (Fullscreen) |
| `H` | Sembunyikan / Tampilkan bar navigasi floating dock |

## 💻 Menjalankan Secara Lokal

```bash
# Clone repositori
git clone https://github.com/turnback2ubuntu-wq/Materi-Kuliah.git
cd Materi-Kuliah

# Masuk ke salah satu pertemuan (misal Pertemuan 3)
cd StatistikTeknik/Pertemuan-3

# Install dependensi (atau symlink dari Pertemuan-1)
npm install

# Jalankan server pengembangan Vite
npm run dev
```
